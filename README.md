# Web Portfolio

Personal portfolio developed using pure HTML and CSS, without frameworks or external libraries.

## Description

Single-page website showcasing professional information, technology stack, and completed projects.

## Technologies Used

| Technology | Usage |
|---|---|
| HTML5 | Site structure and content |
| CSS3 | Styling, responsive design, and animations |

## Project Structure


## Sections

- **About me:** personal introduction and professional summary.
- **Projects:** list of projects with their corresponding image.

## Technical Details

- Layout built with `grid` for content arrangement.
- Images sized with `aspect-ratio` and `object-fit: cover` to prevent distortion.
- Dark color palette with gradient accents (blue, cyan, green).

In development — new sections and style improvements will be added progressively.
